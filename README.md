🎮 Jogo da Imaginação

Um jogo simples em Python onde você escolhe uma ideia criativa e tenta adivinhar qual o "robô" vai sortear.

📋 Como funciona
O jogo mostra 3 opções de ideias para você escolher:
Um carro que anda sobre a água
Uma escola dentro de uma nave espacial
Um relógio que volta 10 segundos no tempo
Você digita o número da sua escolha (1, 2 ou 3).
O robô sorteia aleatoriamente um número de 1 a 3.
Se o seu número bater com o do robô, você acerta!
🛠️ Tecnologias
Python 3
Biblioteca random para o sorteio
▶️ Como rodar
bash
python main.py
